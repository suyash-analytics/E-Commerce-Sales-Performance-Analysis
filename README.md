# 🛒 E-Commerce Sales Performance Analysis | Power BI

**📊 An Interactive Business Intelligence Dashboard for Sales & Profit Analysis**

---

## 📌 1. Project Overview

This project focuses on analyzing E-Commerce sales performance using Microsoft Power BI. It transforms raw sales data into meaningful business insights through interactive visualizations, key performance indicators (KPIs), and dynamic filters.

The dashboard provides an overview of sales trends, profitability, order distribution, and product category performance to support data-driven business decisions.

## 🛠️ 2. Technology Stack

| Tool | Purpose |
|---|---|
| 📊 Microsoft Power BI | Dashboard Development |
| 🔄 Power Query | Data Transformation |
| 🧮 DAX | KPI & Measure Calculations |
| 📈 Data Visualization | Business Insights |

## 📂 3. Dataset Information

The project uses an E-Commerce sales dataset containing **200 records and 12 columns**.

**Key Attributes:**
- Order ID & Order Date
- Customer Name
- State & City
- Category & Sub-Category
- Product Name
- Quantity
- Sales
- Cost Price
- Profit

## 🎛️ 6. Interactive Dashboard Features

The dashboard includes interactive slicers for:
- City
- Month
- State

These filters allow users to explore sales and profitability from different business perspectives.

## 🎯 7. Business Objectives

- Identify high-performing cities and product categories.
- Analyze monthly sales fluctuations.
- Evaluate profitability across different locations.
- Understand order distribution by state.
- Support business decisions through data visualization.
